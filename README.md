# JorPor Prototype

โปรเจกต์ React prototype สำหรับระบบช่วยงาน จป.

## วิธีรันบนเครื่องตัวเอง (ถ้ามี Node.js)
```
npm install
npm run dev
```

## วิธีขึ้นเว็บออนไลน์
ดูขั้นตอนแบบละเอียดในคำอธิบายที่ Claude ให้ไว้ (สรุปสั้น ๆ):
1. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้น GitHub repository
2. ไปที่ vercel.com เลือก "Import Project" แล้วเชื่อมกับ repo นี้
3. กด Deploy รอ 1-2 นาที ได้ลิงก์เว็บที่ใช้งานได้จริง
